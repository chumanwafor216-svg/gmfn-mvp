# DemandBox Opportunity Output Handoff

Date: 2026-11-06

## Owner Direction

The DemandBox message output looked like disconnected blocks and did not carry
the calm, premium quality of the approved recent GSN work. The supplied phone
reference set the direction: a real market-opportunity hero, one coherent white
request paper, visible sender recognition, one primary voice/reply action, a
compact no-match continuation, and a calm lifecycle footer.

## Scope

- Route affected: authenticated `/app/demand-box` only.
- No backend route, model, migration, permission, matching order,
  selected-community contract, Marketplace ownership, Dashboard, Shop,
  Spotlight, or app-shell navigation changed.

## Implemented

- The first surface uses the original project asset
  `frontend/src/assets/dashboard/demand-box-opportunity-hero-v2.webp`, generated
  as a generic high-quality African community market opportunity scene with
  left-side copy space. It is route identity only and is not the requester,
  provider, match, recommendation, availability claim, or evidence.
- An opened phone request is one cohesive white paper with truthful status,
  sender portrait-or-initials, display name, GSN ID when supplied by the API,
  title, area, date, compact request/privacy choices, one blue
  `Listen & reply` disclosure, private-reply notice, protected request audio,
  matches/one-hop search, and a three-action Fulfilled/Cancel/Copy request
  footer.
- WhatsApp Chat and Call remain available under `Privacy & terms`. The former
  dark request hero, always-open reply composer, five-cramped-action row, and
  trailing DemandBox banner are removed.
- For a new `Post a need` form only, a saved shared profile portrait begins
  included and the visible control explains how to turn it off before posting.
  No photo is invented or taken from private identity-check evidence. Replies
  remain separately default-off, and linked reposts retain fresh consent.
  Portraits remain recognition only, never proof of reliability.
- The selected Marketplace identity sits directly above All/For you/Yours
  filters, the secondary route action reads `Ask community`, and the successful
  zero-match continuation reads `No matches here yet` while preserving
  one-hop, withdrawable, non-public, non-paid, non-guaranteed search.
