# GSN External Email Letterhead Template

Date opened: 2026-09-25
Status: active template
Owner: Chukwuma Nwafor / Global Support Network Ltd

## Purpose

External GSN emails should look official, consistent, and human. Use a simple
HTML letterhead when sending Gmail messages through Codex or another email
tool.

This template is for customer discovery, pilot follow-up, partner follow-up,
support-body messages, and founder outreach.

## Truth Boundary

Use **GSN** and **Global Support Network Ltd**.

The verified public domain is:

- `https://globalsupportnetwork.org/`

Do not present `gsn.org`, `jsn.org`, or any shorter domain as owned by GSN
unless ownership is confirmed later.

## Letterhead Structure

Use a clean HTML body:

1. Top band with `GSN` and `Global Support Network Ltd`.
2. Small line: `Community trust infrastructure | globalsupportnetwork.org`.
3. Message content.
4. Signature.
5. Footer with official links.

Avoid large images or remote logo files unless the owner explicitly provides a
stable brand asset. Text-based letterhead is more reliable in Gmail and on
phones.

## Privacy Rule For Pilot Emails

When a pilot involves schools, churches, associations, or other communities:

- ask for named pilot contacts and authority to set up the pilot;
- do not ask for full parent, student, member, or beneficiary data by open email
  unless it is necessary and the organization confirms permission;
- prefer dummy/sample records for the first demonstration;
- only request real personal data after scope, authority, and secure handling
  are agreed.

## Devil Truth

A polished letterhead makes GSN look more serious, but it does not replace real
substance. The body must still be precise, honest, and scoped. Do not use design
to cover uncertainty, overclaim delivery proof, or imply GSN has legal authority
inside an organization before the organization grants it.
