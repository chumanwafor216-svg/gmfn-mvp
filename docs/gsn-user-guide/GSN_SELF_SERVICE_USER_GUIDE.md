GSN is built around a simple truth: the user sets up the real-world basics, then GSN records and presents evidence from what actually happens. GSN does not guarantee a person, approve credit, prove every claim, or replace the judgement of a buyer, community, lender, sponsor, or organisation.

Use this guide in four parts:

A. What you must set up or create.
B. What you do only when needed.
C. What GSN produces or updates automatically.
D. Advanced opportunity capabilities that become useful after enough foundations, evidence, and permissions exist.

## A. What You Must Set Up Or Create

Status: LIVE. Setup requirement: FOUNDATIONAL_REQUIRED.

Status: LIVE. Behaviour: USER_CONFIGURES_OR_CREATES.

Before it works: User must create or sign in to an account.

## Quick Recovery Guide

| Problem | First place to check | What to do next |
|---|---|---|
| No community | Community Home / Join Existing Community | Create or join a community, then retry the feature. |
| Shop not ready | Shop Control | Save shop details and contact path before products or Spotlight. |
| Product/media missing | Shop Assets / Manage Products | Add or replace the product block and media. |
| No public bulletin ready | Community Bulletin / Bulletin Bridge | Post or approve a public bulletin first. |
| DemandBox not posting | DemandBox | Choose community, add required title/question, check feature policy. |
| TrustSlip stale or expired | TrustSlip | Refresh/generate a new current TrustSlip and share the latest code or QR. |
| Analytics feels empty | Shop Control Analytics | Create/share/publish/close real activity, then recheck after responses. |

## Final Evidence Boundary

GSN is an evidence and action system. It helps people set up real records, take structured actions, and show public-safe evidence. It does not secretly decide who is trustworthy. The final decision always belongs to the buyer, community, lender, sponsor, verifier, or organisation receiving the evidence.
